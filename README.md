# VideoOptimizer

`VideoOptimizer` — проста Windows CLI-утиліта для пакетної оптимізації відеофайлів у папці. Вона знаходить відео, створює оптимізовані MP4-файли в окремій папці `_optimized_mp4` і показує, скільки місця вдалося зекономити.

Також є швидкий режим `cut`: він вирізає кілька сегментів з одного MP4-файлу і склеює їх в один MP4 без перекодування відео.

Окремо доступний Windows-інтерфейс `VideoOptimizerGui.exe` для зручного вибору MP4-файлу, папки результату та будь-якої кількості інтервалів.

Утиліта не реалізує власний відеокодек. Вона є C++-обгорткою над `ffmpeg.exe` та `ffprobe.exe`: C++ відповідає за пошук файлів, перевірки, безпечні імена результатів, запуск процесів і звіт.

## Що створюється

Вхідні формати:

- `.mp4`
- `.mov`
- `.mkv`
- `.avi`
- `.webm`
- `.m4v`

Вихідний формат завжди `.mp4`.

Приклад:

```powershell
input:  D:\Videos\test.mov
output: D:\Videos\_optimized_mp4\test.mp4
```

Якщо файл з таким іменем уже існує, буде створене безпечне ім'я:

```text
test_optimized.mp4
test_optimized_2.mp4
test_optimized_3.mp4
```

У режимі `--recursive` результати файлів із вкладених папок складаються в `_optimized_mp4` зі збереженням відносної структури підпапок.

## FFmpeg

Потрібні `ffmpeg.exe` і `ffprobe.exe`.

Утиліта шукає їх:

1. У `PATH`.
2. У підпапці біля `VideoOptimizer.exe`:

```text
tools\ffmpeg\bin\ffmpeg.exe
tools\ffmpeg\bin\ffprobe.exe
```

Якщо FFmpeg не знайдено, програма виведе:

```text
FFmpeg not found. Install FFmpeg or place ffmpeg.exe and ffprobe.exe into tools\ffmpeg\bin.
```

### Як встановити FFmpeg

Варіант 1: додати FFmpeg у `PATH`.

1. Завантажте Windows build FFmpeg з офіційного сайту або надійного дистрибутива.
2. Розпакуйте архів.
3. Додайте папку `bin`, де лежать `ffmpeg.exe` і `ffprobe.exe`, у системну змінну `PATH`.
4. Перевірте в PowerShell:

```powershell
ffmpeg -version
ffprobe -version
```

Варіант 2: покласти FFmpeg поруч з програмою:

```text
VideoOptimizer.exe
tools\ffmpeg\bin\ffmpeg.exe
tools\ffmpeg\bin\ffprobe.exe
```

## Збірка у Visual Studio 2022

1. Відкрийте `VideoConverter.sln` у Visual Studio 2022.
2. Виберіть конфігурацію `Release` і платформу `x64`.
3. Виконайте `Build Solution`.
4. Готовий файл буде в:

```text
bin\x64\Release\VideoOptimizer.exe
bin\x64\Release\VideoOptimizerGui.exe
```

Також можна зібрати через Developer PowerShell for VS 2022:

```powershell
msbuild VideoConverter.sln /p:Configuration=Release /p:Platform=x64
```

## Приклади запуску

Запустити в поточній папці:

```powershell
.\VideoOptimizer.exe
```

Передати папку:

```powershell
.\VideoOptimizer.exe "D:\Videos"
```

Обробити вкладені папки:

```powershell
.\VideoOptimizer.exe "D:\Videos" --recursive
```

Задати параметри якості:

```powershell
.\VideoOptimizer.exe "D:\Videos" --crf 22 --preset slow --fps 30 --max-height 1080
```

Перезаписувати однакові вихідні файли:

```powershell
.\VideoOptimizer.exe "D:\Videos" --overwrite
```

Перевірити без запуску FFmpeg:

```powershell
.\VideoOptimizer.exe "D:\Videos" --dry-run
```

Рекомендований режим:

```powershell
.\VideoOptimizer.exe "D:\Videos" --recursive --crf 22 --preset slow --fps 30 --max-height 1080
```

## Windows-інтерфейс

Після збірки запустіть:

```powershell
.\bin\x64\Release\VideoOptimizerGui.exe
```

У вікні можна:

- обрати один MP4-файл;
- побачити тривалість відео у форматі години:хвилини:секунди;
- обрати папку, куди зберегти результат;
- вручну задати назву результату або залишити поле порожнім;
- додати будь-яку кількість інтервалів `START-END`;
- видалити окремий інтервал або очистити весь список;
- створити один MP4 з усіх вибраних інтервалів через швидкий режим `-c copy`.

Логіка імен результату:

- якщо вибрана інша папка і назву вручну не задано, результат зберігається з оригінальною назвою файлу;
- якщо вибрана та сама папка, де лежить оригінал, результат отримує назву з унікальним id, наприклад `video_cut_17784179600041788.mp4`;
- якщо назву задано вручну, вона використовується в обраній папці, `.mp4` додається автоматично;
- оригінальний файл не перезаписується.

У GUI також є `Dry-run`: він показує FFmpeg-команди без створення файлів.

## Швидке вирізання і склеювання сегментів без перекодування

Режим `cut` бере один MP4-файл, вирізає задані діапазони часу і склеює їх в один результат:

```powershell
.\VideoOptimizer.exe cut "D:\Videos\big.mp4" --segments "00:01:00-00:02:00,00:05:00-00:06:00,00:10:00-00:15:00" -o "D:\Videos\result.mp4"
```

Коротший формат часу також підтримується:

```powershell
.\VideoOptimizer.exe cut "D:\Videos\big.mp4" --segments "1:00-2:00,5:00-6:00,10:00-15:00" -o "D:\Videos\result.mp4"
```

Підтримувані формати часу:

- `SS`
- `MM:SS`
- `HH:MM:SS`
- `HH:MM:SS.mmm`

Приклади сегментів:

```text
60-120
1:00-2:00
00:01:00-00:02:00
00:01:00.500-00:02:10.000
```

Параметри режиму `cut`:

- `--segments "START-END,START-END"` — список сегментів.
- `-o`, `--output FILE` — шлях до вихідного MP4. Якщо не вказано, створюється `input_cut.mp4` поруч з оригіналом.
- `--overwrite` — дозволити перезапис output-файлу.
- `--keep-temp` — не видаляти тимчасові `part_001.mp4`, `part_002.mp4` після успішного завершення.
- `--dry-run` — показати FFmpeg-команди без виконання.

Якщо output уже існує і немає `--overwrite`, буде створене безпечне ім'я:

```text
input_cut.mp4
input_cut_2.mp4
input_cut_3.mp4
```

Оригінальний файл не змінюється. Тимчасові файли видаляються тільки після успішного завершення, якщо не вказано `--keep-temp`.

Режим `cut` дуже швидкий, бо використовує FFmpeg з `-c copy` і не перекодовує відео. Через особливості H.264/MP4 точка різу може бути не ідеально точною до кадру, якщо вона не збігається з keyframe. Це нормальна поведінка для швидкого режиму без перекодування. Для абсолютно точного різу потрібен окремий режим з перекодуванням, який може бути доданий пізніше.

Для тесту спочатку використовуйте:

```powershell
.\VideoOptimizer.exe cut "D:\Videos\big.mp4" --segments "1:00-2:00" --dry-run
```

## Параметри

- `--crf N` — якість H.264, за замовчуванням `22`.
- `--preset NAME` — preset x264, за замовчуванням `slow`.
- `--fps N` — FPS результату, за замовчуванням `30`.
- `--max-height N` — максимальна висота, за замовчуванням `1080`.
- `--audio-bitrate RATE` — бітрейт AAC, за замовчуванням `160k`.
- `--recursive` — обробляти вкладені папки.
- `--overwrite` — перезаписувати існуючий результат з базовим іменем.
- `--dry-run` — показати файли, майбутні результати та FFmpeg-команди без конвертації.
- `--help` — показати довідку.

## CRF

CRF керує якістю та розміром H.264:

- `18-20` — майже без втрати, більший файл.
- `21-23` — хороший баланс якості та розміру.
- `24-28` — сильніше стискання, можлива помітна втрата.

## Цільові параметри

Утиліта формує MP4 з такими параметрами:

- контейнер: MP4;
- відео: H.264 / `libx264`;
- pixel format: `yuv420p`;
- CRF: `22` за замовчуванням;
- preset: `slow` за замовчуванням;
- FPS: `30` за замовчуванням;
- максимальна висота: `1080` за замовчуванням;
- відео нижче заданої висоти не збільшується;
- аудіо: AAC, `160k`, `48000 Hz`, stereo;
- MP4 faststart: `-movflags +faststart`.

## Безпечна логіка

- Оригінальні файли не змінюються і не видаляються.
- Результат пишеться в `_optimized_mp4`.
- Файли, які вже лежать у `_optimized_mp4`, не обробляються повторно.
- Для тесту спочатку використовуйте `--dry-run`.
- Якщо результат не сподобався, оригінал залишається на місці.
- Якщо результат став більшим за оригінал, файл не видаляється автоматично, але це показується у статусі та summary.
